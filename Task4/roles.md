| Роль            | Права роли                                                                                                                            | Группы пользователей          | 
|-----------------|---------------------------------------------------------------------------------------------------------------------------------------|-------------------------------|
| `cluster-admin` | полный доступ к кластеру (управление нодами, неймспейсами, аддонами, восстановление), роль существует по дефолту                      | не выдавать без необходимости |
| `secret-reader` | `get/list/watch` по `secrets` и `configmaps` во всех неймспейсах + чтение остальных ресурсов                                          | специалисты по ИБ             | 
| `pod-developer` | в своём неймспейсе: `get/list/watch/create/update/patch` по `pods`, `deployments`, `services`, `configmaps`; чтение `secrets` и логов | developers                    | 
| `pod-reader`    | только `get/list/watch` по `pods`, `services`, `deployments`, `pods/log` без прав изменять и без доступа к секретам                   | viewers (напр, аналитики)     |
